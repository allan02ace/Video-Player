# AMPM Player

A phone-first video player that runs in the browser. It opens on the folder list, plays a video when you tap it, and asks whether to continue or start over if you watched it before. It also supports SRT subtitles with timing adjustment.

## Put it online with GitHub Pages
1. Create a repository and upload everything in this folder (keep the `icons` folder).
2. Open Settings, then Pages. Under Branch choose `main` and `/ (root)`, then Save.
3. Open the link GitHub gives you (it ends in `github.io/<repo>/`).

## Install on a phone
- Android (Chrome): menu, then Install app.
- iPhone (Safari): Share, then Add to Home Screen.

Videos stay on your device and are never uploaded. Browsers can't keep access to your files between visits, so add your videos again each time. Resume positions are remembered per file (name, size and date).
